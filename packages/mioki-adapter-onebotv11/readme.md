# mioki-adapter-onebotv11

OneBot v11 adapter for the [mioki](https://github.com/vikiboss/mioki) framework (implemented on NapCat).

This package is the first reference implementation of a mioki adapter. It maps
OneBot v11 protocol (NapCat) to mioki's platform-agnostic `Adapter`, `Bot`,
`Event` and `Capability` contracts.
